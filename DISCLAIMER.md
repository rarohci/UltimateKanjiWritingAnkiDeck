# Disclaimer and known limitations

## Educational use and accuracy

This deck is a study aid. Readings, definitions, translations, vocabulary, and
level assignments may be incomplete, outdated, or incorrect. Check uncertain
entries against a reliable dictionary or a teacher. No learning outcome or
exam result is guaranteed.

## Handwriting recognition

The writing card compares a stroke with generated reference data using the
bundled Hanzi Writer code. It can reject reasonable handwriting or accept an
imperfect stroke. Short strokes, tight bends, hooks, and alternate forms can be
particularly sensitive. Acceptance is feedback for practice, not an authoritative
assessment of handwriting. Review grades remain the learner's choice.

## Compatibility and previews

The card previews were rendered in a desktop browser from the source templates
using the deck's 漢 note. Browser rendering is not a complete test in Anki
Desktop, AnkiDroid, AnkiMobile, or AnkiWeb. No complete client/version test matrix
is currently published. JavaScript behavior, fonts, gestures, viewport sizing,
and system theme detection can vary between clients.

Repository templates and documentation can change after a release. Downloaded
packages contain the templates bundled when that package was built; editing or
pulling source files does not update an installed deck.
